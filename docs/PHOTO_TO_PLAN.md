# План по фото

doplan умеет превратить изображение планировки в редактируемый проект `.doplan` со стенами, комнатами,
дверями, окнами и исходной картинкой-подложкой. Подходят:
- скан или фото плана БТИ;
- поэтажный план и экспликация;
- планировка застройщика;
- скриншот с сайта ЖК;
- аккуратный эскиз от руки с размерами.

Есть два пути: через Claude Code (точнее, с проверками и итерациями) и прямо в приложении (быстрее, нужен
API-ключ Anthropic).

## Способ 1. Claude Code (рекомендуется)

### Что нужно
Нужен Claude Code, открытый в папке репозитория doplan. Скил `photo-to-plan` лежит в
`.claude/skills/photo-to-plan/` и подключается автоматически.

### Как отправить план
- Положите файл в папку `inbox/` в корне репозитория (или в любое место) и напишите:
  > Нарисуй планировку по `inbox/plan.jpg`. Высота потолков 2,7 м.
- Или вставьте картинку прямо в чат (Ctrl+V) и напишите «перенеси этот план в doplan». Claude
  сохранит изображение из буфера обмена командой `pnpm dp img paste`.
- PDF и HEIC пока не читаются: сохраните страницу как PNG/JPG или сделайте скриншот.

Полезно сразу сообщить:
- высоту потолков;
- где вход;
- какие стены несущие, если это известно;
- нужен ли только один уровень или страница с несколькими квартирами (какая из них ваша).

### Что происходит
1. **Подготовка.** Картинка поворачивается по EXIF, обрезается, выравнивается по наклону и
   контрастируется. Результат сохраняется в `.doplan-work/<имя>/work.png`.
2. **Чтение.** Claude рассматривает план целиком и по фрагментам с координатной сеткой. Сначала он
   выписывает все размеры, названия и площади помещений, затем данные экспликации.
3. **Масштаб.** Масштаб определяется по напечатанным размерам: самый длинный размер плюс
   проверочные. Если размеров нет, он считается по площадям комнат.
4. **Черновик.** Claude пишет описание плана в формате PlanSpec (JSON, в миллиметрах). Стены
   получаются из промежутков между комнатами, их толщина округляется до стандартной.
5. **Проверка.** Валидатор сверяет замкнутость комнат, двери, вход и вычисленные площади с
   подписанными на плане.
6. **Сравнение с оригиналом.** Чертёж рисуется поверх исходного изображения, расхождения выделяются
   рамками. Claude исправляет черновик, не больше 4 кругов.
7. **Сборка.** Получается файл `.doplan` с подложкой на отдельном заблокированном слое. Его можно
   сразу открыть в приложении.
8. **Отчёт.** Claude показывает площади по комнатам («вычислено / по плану») и перечисляет всё, что
   пришлось предположить: неподписанную толщину стен, направление открывания дверей, неразборчивые
   цифры.

Все промежуточные файлы остаются в `.doplan-work/`: рендеры, наложения, JSON-черновики. Если что-то
не так, скажите Claude, например «стена между кухней и комнатой несущая» или «санузел шире на 20 см».
Он поправит черновик и пересоберёт проект.

### Команды для самостоятельной работы
| команда | что делает |
|---|---|
| `pnpm dp img prep <файл> --out <папка> [--deskew] [--contrast]` | подготовка изображения |
| `pnpm dp img prep <файл> --out <папка> --perspective x1,y1,…,x4,y4 [--rect-mm Ш,В]` | выравнивание фото, снятого под углом: 4 угла прямоугольника (наружные стены или рамка листа) в пикселях оригинала, в любом порядке; `--rect-mm` — его реальный размер в мм |
| `pnpm dp img grid <png> --out grid.png` | координатная сетка поверх плана |
| `pnpm dp spec validate <spec.json>` | проверка PlanSpec и площадей |
| `pnpm dp spec overlay <spec.json> --image work.png --out ov.png` | наложение чертежа на оригинал |
| `pnpm dp spec build <spec.json> --out План.doplan --open` | сборка проекта и открытие приложения |
| `pnpm dp doc info <проект.doplan>` | состав проекта и площади |

Полный список команд выводит `pnpm dp help`. Пример PlanSpec лежит в
`tools/dp/examples/two-room.planspec.json`, справочник формата — в
`.claude/skills/photo-to-plan/planspec-reference.md`.

## Способ 2. Прямо в приложении (API-ключ)
1. Откройте **Настройки** и введите API-ключ Anthropic. Ключ хранится локально и используется только
   для распознавания.
2. Выберите **Файл → «План по фото…»** (или «Фото → план» на стартовом экране) и укажите изображение.
   Можно добавить подсказку, например «потолки 2,7, вход снизу».
3. Приложение отправит картинку модели Claude, получит PlanSpec, покажет предупреждения проверки и
   построит план с подложкой.

Этот путь быстрее, но делает один проход без итеративного сравнения с оригиналом. Проверьте размеры и
площади вручную. Готовый PlanSpec JSON (например, полученный в Claude Code) импортируется через
**Файл → «План из PlanSpec (JSON)…»**.

## Ограничения
- **Только планы.** Фотографии реальных комнат, интерьеров, 3D-визуализации и фасады не подходят:
  по ним нельзя надёжно восстановить планировку. В этом случае опишите размеры словами, и Claude
  нарисует план по ним.
- Точность зависит от источника. Напечатанные размеры дают точность до сантиметров. Без размеров
  масштаб берётся из площадей, и погрешность составляет несколько процентов. Эскизы «не в масштабе»
  строятся только по цифрам.
- Перспектива (фото под углом) исправляется по четырём углам прямоугольника: `img prep --perspective`
  или кнопка «Выровнять перспективу» в свойствах подложки. Изогнутый лист так не выпрямить: снимайте
  строго сверху или сканируйте.
- Стены строятся ортогонально. Скошенные стены и эркеры передаются многоугольником, а дуги
  аппроксимируются.
- Один план — один уровень. Для дома из нескольких этажей обрабатывайте каждый этаж отдельно.
- Мебель по умолчанию не переносится, кроме сантехники, плиты, стояков и вентшахт.
- Всё, что не удалось прочитать однозначно, явно перечисляется в отчёте и в `notes` проекта. Это
  стоит проверить.
